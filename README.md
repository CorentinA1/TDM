# TDM — Trophée Départemental des Mixtes pour IANSEO

**Version 1.3.4**

Module IANSEO pour organiser une manche de **Trophée Départemental des Mixtes** (règlement FFTA 2026) :
qualification par équipe mixte (feuille papier ou Scorekeeper), tour de poules en sets, Big Shoot Off et classement
final à points.
Il s'appuie sur IANSEO (sessions, cibles, épreuves par équipe, poules Round Robin, saisie des matchs)
et ajoute ce qu'IANSEO ne fait pas pour le TDM.
Une compétition IANSEO = une manche : le cumul de deux manches n'est pas encore géré.

> **Module indépendant, sans garantie ni SAV.** Il n'est pas développé par l'équipe IANSEO (ianseo.net) ni par la
> FFTA. Il peut contenir des bugs, jusqu'à bloquer IANSEO : **sauvegardez vos compétitions** avant et pendant
> leur déroulement. Voir [À lire avant d'utiliser le module](docs/AVERTISSEMENT.md) (sauvegardes, licences).

## Installation rapide

1. Télécharger `TDM-vX.Y.Z.zip` dans **Releases**.
2. Le décompresser dans `Modules/Custom/` d'IANSEO : le dossier doit s'appeler `TDM`.
3. Ouvrir une compétition : **Modules → Trophée des Mixtes → Configuration**.
